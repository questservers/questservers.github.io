What's inside

Everything the editor should have shipped with

Two GUIs, one folder: AI lives in the editor, themes and tweaks live in the toolbar popup. Both read the same settings, so a change in the popup lands on open editor tabs instantly.

✦

AI Studio

Prompt → part list → validated invention. Build, Data and Settings tabs, plus generated item art. Every model call runs in the extension's service worker.

◐

24 themes

An accent override, a 9-slot custom palette, portable JSON and your own CSS. They restyle the editor's variables and its hard-coded surfaces.

⚙

Editor tweaks

Panel opacity, backdrop blur, corner radius, text size, thumbnail width, fonts, compact spacing, glow, reduce motion and a long declutter list.

◍

Streamer mode

Hides your in-game name, the Prime recovery session and the build signature across page text, AI Studio and copied dossiers. Item names stay readable.

▤

Revamp shell

◈

Live catalog data

Banned item badges, hide-banned filtering and the current build limits read straight from items.json, build-security and the goop policy.

Install

Four steps, about two minutes

Chrome does not load extensions from a zip, so you unpack it once and point Chrome at the folder. Keep that folder where it is — Chrome reads the extension from its path on every start.

1

Download the zip

Grab the packaged extension below. If you are on a GitHub release page, use the attached zip — not the green Code button, which gives you the source tree.

mikeybox-toolkit-1.8.0.zip Download

99 KB · 14 files · SHA-256 in the footer

2

Extract it

Right-click → Extract all on Windows, or double-click the zip on macOS. You want a folder called mikeybox-toolkit that contains manifest.json.

Pick the folder holding manifest.json, not the one above it. That is the usual “Manifest file is missing or unreadable” error.

3

Load it in Chrome

Open chrome://extensions, turn on Developer mode, click Load unpacked and select the extracted folder.

chrome://extensions

Edge: edge://extensions · Brave: brave://extensions. Keep it if Chrome offers to disable developer-mode extensions at startup.

4

Open the editor

Reload prime.mikeybox.ai. A floating AI button appears bottom-right; the toolbar icon opens the toolkit GUI.

In AI Studio open Settings, paste a free Gemini key from aistudio.google.com/apikey and press Save & scan models. An NVIDIA nvapi- key also works. The key stays in this browser.

Questions

Before you install

Is this an official Mikeybox, Google or NVIDIA extension?

No. It is an unofficial fan project, not affiliated with Mikeybox, Wooster Games, Meta, Google or NVIDIA. It only reads the editor's public pages and endpoints from your own browser.

Where does my API key go?

Into chrome.storage.local — this browser only, never synced. Only the extension's service worker reads it to call Gemini (or NVIDIA, if you pasted an nvapi- key); it is never written into the editor page, and nothing is sent anywhere else. Clear removes it.

Why does Chrome say “developer mode extensions”?

Unpacked extensions are not store-signed, so Chrome warns at startup and offers to disable them. Choose Keep. If Chrome disables it after an update, press reload on the extension card.

Does it work on Edge, Brave or macOS?

Any Chromium 111+ browser works: use that browser's extensions page and the same Load unpacked flow. The files are platform-independent.

How do I update to a new version?

Replace the contents of the extracted folder with the new build, then press the reload icon on the extension card and reload the editor tab. Your themes, tweaks and key live in Chrome storage, so they survive the update.

Does the AI cost anything?

The extension is free. Builds use your own Gemini key (or an NVIDIA key), each with its own free tier and rate limits — heavy use can hit those, and image editing or 3D are self-hosted NIMs you would run yourself.
